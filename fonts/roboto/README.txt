# Roboto Font Files

Place the following woff2 files in this directory:
- roboto-300.woff2  (Light 300)
- roboto-400.woff2  (Regular 400)
- roboto-500.woff2  (Medium 500)
- roboto-700.woff2  (Bold 700)

Download from: https://fonts.google.com/specimen/Roboto
Or use the Google Fonts Helper: https://gwfh.mranftl.com/fonts/roboto

Until font files are added, the browser will use system Roboto if installed,
or fall back to the system sans-serif font stack.
