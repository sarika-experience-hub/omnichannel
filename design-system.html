azentio Design System

The values and components actually in use across the retail, corporate and pre-login screens. Everything on this page is rendered with the same CSS the product uses, so what you see is what ships.

Root font size is 14px, so 1rem = 14px throughout. Every size comes from the nine --fs-* tokens below, never a raw value.

Colour

Navy carries structure and text, corporate green carries action and affirmation. The brighter #2ed88e is the logo tint — it is used in artwork and on dark grounds, not for text or borders on white, where it is too light to read.

Typography

Poppins for Latin — the primary typeface in the Azentio brand guidelines (§2.1). Poppins carries no Arabic glyphs, so Tajawal is the Arabic companion, with Noto Sans Arabic behind it. Both sit in one stack: browsers resolve fonts per glyph, so Latin takes Poppins and Arabic falls through to Tajawal automatically — mixed strings render correctly with no language switching. The base is 14px and the scale below is the whole system; a size that is not one of these is drift, not hierarchy.

Hero panels

A mint panel carrying a brand mark at 12% opacity over a soft halo. The mark differs by area so the two sides of the product stay distinguishable: petals before sign-in, the triangle after. The decoration lives in its own self-clipping layer so dropdowns inside the hero are free to overflow it.

Links

Three kinds, one definition each. The rule is shared from css/prelogin-header.css so the same kind of link cannot render two ways on two pages.

Links to another page in the product open in the same window. Only genuinely off-site destinations open a new tab, with rel="noopener noreferrer" and data-direct so they skip the new-window confirmation.

Conventions

RuleWhy
Sentence case CTAs"Send message", not "SEND MESSAGE". Pre-login flows use this; older signed-in screens still use caps.
One primary per viewIf everything is emphasised, nothing is.
No icon on a text CTAA row of iconed buttons reads as clutter; the label is enough.
Icons mark sectionsMint tiles in card headers aid scanning; they are not controls.
Tabular figuresAny number that updates or sits in a column.
Page-local overridesNever edit a shared class in styles.css without checking every page that uses it.
Reduced motionEvery transition is disabled under prefers-reduced-motion.

Known gaps — worth closing before this is treated as final:
